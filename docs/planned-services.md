# Planned Microservices Roadmap

To maintain workspace clarity, services are generated on-demand as each vertical slice phase is introduced:

| Service Name       | Description                                | Phase Created | Status  |
| :----------------- | :----------------------------------------- | :------------ | :------ |
| **`scheduler`**    | Schedule CRUD API & database management    | Phase 4       | Planned |
| **`scanner`**      | Partitioned database scanner for due tasks | Phase 5       | Planned |
| **`dispatcher`**   | RabbitMQ job queue publisher               | Phase 6       | Planned |
| **`worker`**       | Task execution engine & history logger     | Phase 7       | Planned |
| **`notification`** | Webhook & alert notification worker        | Phase 9       | Planned |
| **`identity`**     | Auth, JWT, and RBAC user management        | Phase 10      | Planned |
| **`gateway`**      | Unified HTTP/gRPC API Gateway              | Phase 11      | Planned |
